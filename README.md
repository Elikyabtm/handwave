# HANDWAVE

HANDWAVE est un instrument musical contrôlé par gestes, construit avec Next.js, MediaPipe Hands et Tone.js.

## Contrôles

- Main gauche à l'écran : sélection du degré I à VII.
- Main droite à l'écran : sélection du mode d'accord.
- Position verticale de la main droite : volume.
- Position horizontale de la main droite : filtre.

### Modes d'accord

- NORMAL
- OCTAVE -1
- 1ST INVERSION
- MAJ7
- DOMINANT 7

## Lancer le projet

```bash
npm install
npm run dev
```

Puis ouvrir `http://localhost:3000` et autoriser l'accès à la caméra.
